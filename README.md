# Extremes of the two-sided Eulerian statistic

Yitzchak Shmalo

Let T_n = des(π) + des(π⁻¹) for a uniform random permutation π of size n, and let M_n be the maximum of k_n independent copies of T_n. With the Gaussian extreme-value constants, the normalized maximum converges to the standard Gumbel law if and only if log k_n = o(√n). When log k_n / √n → c the limit is the Gumbel law shifted by −c²/10, and when √n ≪ log k_n ≪ n the normalized maximum tends to −∞. A corrected centring gives the standard Gumbel limit for log k_n = o(n^{2/3}), and a centring and scaling defined by the exact cumulant generating function give it for log k_n = o(n). The maxima of des(π_j) and of des(π_j⁻¹) are asymptotically independent, and when log k_n / √n → c each limit is the Gumbel law shifted by −c²/5. This answers two questions of Dörr and Heiny.
